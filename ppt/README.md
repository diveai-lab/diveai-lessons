# ppt/ — PowerPoint 版投影片

## 定案：`diveai-ocean-template.pptx`（A 海洋潛水風）

日後所有 .pptx 都從這一份複製出來，成品放 `ppt/<slug>.pptx`。共 4 頁：前 3 頁是範例內容，**第 4 頁是色票頁**（現場用滴管取色最快）。

| 項目 | 值 |
|---|---|
| 標題字 | **Noto Sans TC Bold** |
| 內文字 | **Yuanti TC Bold** |
| 背景 | `#F4FAFC` |
| 標題條 | `#8FCFE2`（框線 `#4E93AF`） |
| 頁尾品牌帶 | `#5FA8C4` |
| 標籤藥丸／強調字 | `#2E5C74` |
| 版面 | 26.67″ × 15″（16:9），11 個版面配置，內頁用「標準只帶標題」 |

**卡片色（8 組，框線／底色）**：天藍 `#5FA8C4`/`#E9F4FA`、湖水綠 `#7CCBC9`/`#E4F5F4`、腮紅粉 `#F4B3BE`/`#FDEDF0`、暖黃 `#E8C46A`/`#FFF7E0`、薰衣草 `#A9A7D4`/`#EFEEF9`、珊瑚橘 `#F0A07C`/`#FDEEE5`、抹茶綠 `#A7C796`/`#EFF6EA`、霧灰藍 `#8FA3B0`/`#EDF1F4`。
**狀態色**：提醒 `#E2725C`、成果 `#6FB98F`、提示 `#E8C46A`。
完整規則（圖表色序、白字安全底色、元件配方）在 `diveai-pptx` skill 的 `references/palette.md`。

## 備援風格（確認不需要就可以刪）

| 檔案 | 風格 | 適合 |
|---|---|---|
| `style-a-ocean-dive.pptx` | A 海洋潛水風（＝定案，無色票頁） | — |
| `style-b-cream-note.pptx` | B 奶油手帳風（腮紅粉＋暖米，Yuanti TC Bold） | 工作坊、學生場合 |
| `style-c-mint-clean.pptx` | C 薄荷清爽風（湖水綠＋近白底，PingFang TC） | 對外演講、評審 |

三款骨架完全相同，只差配色與字型。

## 注意

- 字型要 Mac 上有裝才不會跑版：Noto Sans TC、Yuanti TC（圓體）、PingFang TC（macOS 內建）。
- 範例第 3 頁「AI 模型」對話框文字會擠成兩行、略微溢出——這是原範本就有的，尚未修。
