## S9・潛點 2｜分數怎麼變機率？
- 標題：〔潛點 2〕分數怎麼變機率？
- 前言：呆一布看了一張圖，吐出三個分數：
- 三張分數卡：🐱 貓 ＝ 2　／　🐶 狗 ＝ 1　／　🐰 兔 ＝ **−1**（紅字）
- 大哉問：它要說「我有 **70%** 確定是貓」——這 70% 哪來的？
- 小字規則：規則只有一條：所有機率加起來 ＝ 1，而且每個都 ≥ 0。

## S10・你來發明！（學習單常駐頁）
- 任務標：📄 學習單 · 10 分鐘（配 `worksheet-softmax.pdf`）
- 標題：你來發明！
- 三關卡：
  - 第一關｜**直接「除以總和」**：算算看兔子的機率 → 會算出 −0.5，怪怪的 🤨
  - 第二關｜**那「取絕對值再除」呢？**：檢查貓＞狗＞兔的大小順序有沒有被弄壞。
  - 第三關｜**想一個辦法…**：讓所有數字「都變正、順序又不變」。
- 人物：DIVE 思考＋對話框（口頭提示）「數學課有個函數，輸入任何數、輸出永遠是正的？」

## S11・揭曉：你發明了 softmax！
- 標題：揭曉：你發明了 softmax！
- 計算方塊：e² ≈ **7.39**　e¹ ≈ **2.72**　e⁻¹ ≈ **0.37**　總和 ≈ **10.48**
- 機率長條：🐱 貓 70%　🐶 狗 26%　🐰 兔 4%
- 一句：都變正、順序不變、加起來剛好 ＝ 1 ✓　這就是**深度學習最常用的輸出層**！
- 公式（最後才出現）：（公式現在才出現，因為你們已經懂了：softmaxᵢ ＝ eˣⁱ ⁄ Σ eˣ）

## S12・潛點 3｜LLM 其實在做什麼？
- 標題：〔潛點 3〕LLM 其實在做什麼？
- 主張句：它在做的事，其實只有一件：<u>看前面的字，猜下一個字</u>。

## S13・選字，就是用 softmax 選的！
- 標題：選字，就是用 softmax 選的！
- 前言：每個字先給一個編號，模型對「下一個字」吐出一堆分數：
- 流程圖：前面的字 → 呆一布（dive_explain）→ 每個字的分數 → softmax → 機率
- 一句：還記得潛點二嗎？**softmax** 把分數變成機率，再從裡面**抽一個字**——這就是它「說話」的方式。

## S14・你們就是一台 LLM！（真人 LLM 接龍）
- 任務標：👥 真人 LLM · 接龍
- 標題：你們就是一台 LLM！
- 字卡示意：今｜天｜天｜氣　→　？｜？｜…
- 便利貼〈玩法〉：給一個開頭，組內同學**輪流、一次只加一個字**，接成一句話。跟別組同開頭比比看——**結果差多少？**
- 人物：同學貼圖 student1（側邊）

## S15・LLM 生成的，都是「幻覺」
- 標題：LLM 生成的，都是「幻覺」
- 主張句：它每一次都是「<u>生成</u>」，不是「查到真相」。
- 粉色便利貼：所以要有批判性思考 🧠　特別是 AI 幫你寫的作業、報告——**一定要讀完、真的懂、改過**，變成你自己的東西，才能交出去。
- 人物：DIVE 困惑（側邊）
- 用詞：沿用專案定調，LLM 的生成一律稱「幻覺」

## S16・寫 Prompt 沒那麼難
- 標題：寫 Prompt 沒那麼難
- 兩張貼紙卡：
  - `1` **提供正確的資訊**：它不知道你腦中的背景——把該給的資料、條件講清楚。
  - `2` **給清楚的指引**：要它做什麼、輸出成什麼樣子、給誰看，講明白。
- 一句：兩個重點而已：**正確的資訊 ＋ 清楚的指引**。

## S17・必殺技：和 AI 一起「來回」工作
- 標題：必殺技：和 AI 一起「來回」工作
- 循環圖：先粗略問 → 看結果 → 補資訊／加限制／給範例 ↻ …再問一次！
- 便利貼〈👥 快問快答〉：爛 prompt：「幫我寫報告。」——各組喊一句，**你會補什麼讓它變清楚？**
- 一句：好 prompt 不是一次寫對的，是**磨**出來的。

## S18・潛點 4｜教 AI 跑腿：AI Agent
- 標題：〔潛點 4〕教 AI 跑腿：AI Agent
- 前言：不只「你問一句、它答一段」，而是為了達成目標，自己一步步行動：
- 流程圖：目標 → 拆解任務 → 用工具 → 看結果 → 調整 → 完成
- 一句：把「人怎麼把事做好」拆成步驟教給它——這就是 Agent（吳恩達的 agentic design pattern 也是這概念）。
- 人物：DIVE 解說（側邊）

## S19・規劃一場班遊！（真人 Agent 角色分配）
- 任務標：👥 真人 Agent · 角色分配（配 `worksheet-agent-rolecard.pdf`）
- 標題：規劃一場班遊！
- 六張角色卡：
  - 🧠 **LLM**：只能用嘴巴想、說話，**不准自己查任何東西**。
  - 🔢 **工具 A · 計算機**：只回答算式的答案。
  - 🔍 **工具 B · 搜尋**：可用手機查，只回傳查到的內容，不給意見。
  - 📅 **工具 C · 行事曆／地圖**：回傳日期、路線之類的事實。
  - 📝 **記錄員**：記下 LLM 每次「呼叫了哪個工具、輸入什麼」。
  - 🎯 **任務**（虛線卡）：每人 **500 元**內的班遊。LLM 每次要明說「我要呼叫○○，輸入是…」。
